# Roadmap

## Now

- Get the shipped beta in front of people: the launch chunks in `HANDOFF.md`
  (OBS smoke test, demo clip, KVR listing, one Reddit post, a month of listening).
  Decision: [ADR 0008](decisions/0008-v0.2-is-distribution.md).

## Next

- Add record status/path feedback that fits the system UI.
- Add export-size controls if editor-size recording is not enough.
- Consider an audio include/exclude control if silent visual exports become common.
- Smoke test Syphon External Source against current macOS live visual tools.
- Evaluate NDI or a true virtual camera only if Syphon is not enough.

## Later

- MIDI/note-assisted period lock.
- Preset-safe migrations for any new parameters.
- Windows/Linux feasibility only after macOS behavior is solid.
