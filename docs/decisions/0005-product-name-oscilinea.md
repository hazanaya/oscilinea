# 0005 - Product Name: Oscilinea

## Status

Accepted

## Context

The project needs a distinctive public name before broader beta sharing. Lightweight name research found the prior working name crowded in adjacent audio, audiovisual, and entertainment contexts.

## Decision

Use **Oscilinea** as the product and documentation name.

## Consequences

- Documentation, package copy, installer text, and user-facing labels should use Oscilinea.
- Build products and bundle metadata should be aligned before the next distributable beta package is sent out.
- After beta distribution begins, plug-in identity values and parameter IDs should be treated as host/session contracts.
