# 0008 - v0.2 Is Distribution, Not Features

## Status

Accepted (Haza, 2026-10-30)

## Context

The first public beta shipped on 2026-08-01 (GitHub release plus the
hazaelanaya.com/oscilinea page). Three months later the installer had been
downloaded twice. Nothing is broken; nobody has found it.

The open product question in the handoff was whether v0.2 should add NDI or a
true virtual-camera output. NDI moves video between computers on a network;
Oscilinea's users run everything on one Mac. OBS already takes Oscilinea through
its built-in Syphon Client source, and OBS itself provides a virtual camera to
any other app, so OBS users are covered. A native virtual camera would only
serve people who skip OBS, and none has asked.

## Decision

Oscilinea is a live project worked in small chunks. The next work is getting the
existing beta in front of people, not adding output paths:

- Verify the OBS path once (it was listed as a smoke test, never recorded as done).
- Record a short demo clip with Oscilinea's own recorder.
- List the plug-in on KVR Audio and post it once, with the clip, on Reddit.
- Watch downloads and comments for a month and collect feedback.

NDI and a virtual camera stay deferred until user feedback asks for them
(ROADMAP: "only if Syphon is not enough").

## Consequences

- `HANDOFF.md` Next Steps become the launch chunks; any session can pick one up.
- The version stays `0.0.1-beta.20260801` until feedback justifies a release.
- Posting and account creation (KVR, Reddit) are Haza's own actions; the hub
  drafts text and watches numbers.
